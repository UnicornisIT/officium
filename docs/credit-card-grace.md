# Условия льготы кредитной карты

Отсутствие даты окончания льготы больше не означает отсутствие процентов.
В форме долга можно явно выбрать отсутствие льготы либо договорное правило
её потери: проценты после окончания или с начала периода.

Старые записи сохраняют `grace_policy = NULL`: миграция добавляет только
nullable-колонку и не изменяет финансовые записи. При неизвестных условиях
или потере льготы без выбранного правила интерфейс показывает требование
сверки. API возвращает `calculation_status = needs_reconciliation`,
`calculation_valid = false`, `accrued_interest = null` и `total_debt = null`.
Внутренние числовые поля состояния нужны для обработки сохранённой истории;
при таком статусе их нельзя использовать как подтверждённые начисления.
Ручная разбивка банка сохраняется, но не определяет условия договора.

Перед развёртыванием выполните штатное обновление схемы до ревизии
`20261202_card_grace`. Проверка на временной SQLite сохраняет старые NULL
и даты без изменений; автономная генерация MySQL DDL не содержит UPDATE.
Реальные базы при проверках не изменяются. Сверьте договор каждой старой
карты перед выбором правила: изменение настроек запускает существующий
механизм перерасчёта платежей. Автоматически назначать правила всем картам
нельзя.
