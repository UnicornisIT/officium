# Этап 7 — аналитика стоимости владения

База: `origin/master` `b8518da`, проверена 1 ноября 2026 года. Этапы 4, 5 и 6 присутствуют. Работа выполнена в отдельном worktree `.tmp/vehicles-stage7`, ветвь `feature/vehicles-stage-7-tco`, чтобы сохранить локальные изменения исходного каталога.

## Реализация и правила расчёта

- `/vehicles/tco`: текущий год по умолчанию, период и несколько автомобилей, сводка и сравнение по убыванию общей суммы, CSV.
- Карточка `?tab=tco`: те же фильтры и графики одного автомобиля, прогноз. Для прицепов доступны траты и категории без километровых показателей.
- Личные расходы и расходы организации учитываются по датам финансовых записей. Заправки и документы со связанной тратой не добавляются повторно, даже если сумма документа отличается от сохранённой суммы траты.
- Документ без связанной траты с суммой и датой выдачи включается в личное страхование на дату выдачи. У документа нет собственного плательщика; без даты выдачи сумма не включается. Это правило явно показано на странице.
- Литры, средневзвешенная цена и расход рассчитываются по существующим правилам топливного сервиса, включая неполные заправки между полными.
- Пробег за период: последний замер минус первый внутри периода. Для помесячного графика используются замеры внутри каждого месяца; месячные километры могут не суммироваться в пробег всего периода. Нет двух замеров — стоимость километра отсутствует; есть пробег, нет трат — 0,00 ₽/км.
- Прогноз использует до шести завершённых месяцев, начиная с первого месяца с тратами в этом окне. Последующие нулевые месяцы учитываются. Менее трёх месяцев — нет прогноза. Для шести месяцев тренд сравнивает 3+3, для 3–5 — раннюю и позднюю половины (при нечётной длине поздняя длиннее). Тренд вне [-20%; +50%] подавляет прогноз. Текущий неполный месяц исключён. Это уточняет неопределённый случай 3–5 месяцев в исходном промте.
- Новых таблиц и миграций нет. Период ограничен 120 календарными месяцами.
- В `finance.html` и `app.js` нет Chart.js/D3: существующая аналитика использует CSS. Добавлена локальная Chart.js 4.4.8 с MIT-лицензией; внешних запросов графиков при работе приложения нет.
- Таблицы значений под графиками доступны без JavaScript. Фокус клавиатурой на строке показывает соответствующую подсказку диаграммы. Пропуски километров не соединяются линией.

## Автоматические проверки

`python -m unittest discover -s tests -p test_vehicle_tco.py -q`: 6 тестов пройдены. Проверены суммы и категории, смешанные плательщики, несколько автомобилей, пустые данные, прицепы, стоимость километра, история, прогноз, топливо и документы без двойного учёта, приватность, флаг, даты, CSV и журнал.

`python -m unittest discover -s tests -p 'test_vehicle*.py' -q`: 389 тестов, OK, 1 skipped; миграционные проверки не обнаружили новых операций.

Производительность на SQLite в памяти, 50 авто × 12 месяцев (600 расходов и 1200 замеров): 0,136–0,501 с, 6–7 SQL-запросов; 10 авто: 0,118 с. Жёсткого временного assert нет; проверяется отсутствие N+1. Кэш не требуется. MySQL отдельно не измерялся.

`tests/e2e/vehicle-tco.spec.js` проверяет выбранное авто и даты, таблицу и суммы, реальные пиксели трёх canvas, клавиатурную подсказку, CSV общей страницы и карточки, прогноз и отсутствие горизонтального переполнения страницы. Размеры: 390/1440 px, светлая/тёмная тема, Chromium/Firefox/WebKit.

Итоговый отдельный прогон Chromium + WebKit: **8 passed (3.0m)** — все четыре комбинации размеров и тем для каждого движка, включая CSV карточки.

Firefox в этом Windows-окружении нестабилен: получены зависания создания/закрытия контекста и перехода после загрузки CSV, логи `RenderCompositorSWGL failed mapping default framebuffer` и `NS_ERROR_FAILURE`. Та же проблема зафиксирована в QA этапа 5. Общий прогон: 9 passed, 3 failed (11,6 мин); все три ошибки относятся к Firefox. Успешность всей матрицы Firefox не подтверждена; перед слиянием нужен успешный CI-прогон.

## CSV и приватность

UTF-8 BOM, разделитель `;`, десятичная запятая, суммы до копеек, литры до 0,001. Имена с формульными префиксами защищены апострофом. Нет VIN, госномера, комментариев, названий отдельных расходов. Журнал экспорта: действие и тип `vehicle_tco_export`, ID пользователя, без ID авто, сумм и названий.
