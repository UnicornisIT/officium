## Результаты

- Серверный регрессионный набор: 178 тестов, успешно (автомобили, траты, заправки, обслуживание, документы и миграция документов).
- Chromium: четыре сценария успешно, 390/1440 px, светлая/тёмная тема.
- WebKit: четыре сценария успешно, 390/1440 px, светлая/тёмная тема.
- Firefox: запуск нестабилен в текущем окружении Windows; после выполнения действий и сохранения мобильного скриншота зависает завершение контекста. Полный успешный прогон четырёх вариантов не подтверждён. Требуется повторная проверка в CI до слияния.
- На раннем прогоне обнаружено перекрытие элементов свёрнутой формой в Firefox. Исправлено явным скрытием формы в закрытом details.
- Изменение сроков, восстановление состояния после правки, границы срока и откат транзакций проверены серверными тестами.
- Скриншоты Chromium (мобильная светлая и настольная тёмная темы) просмотрены: поля читаемы, карточки не выходят за экран.
