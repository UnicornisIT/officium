# Исправления после ручной проверки — 31.10.2026

## Результат

Все три найденных недочёта исправлены:

1. При ошибке сохранения сервер возвращает страницу с HTTP 422 и раскрытой формой. Введённые поля, тип документа, плательщик и флаг создания траты остаются в форме. Данные повторной попытки не помещаются в сессию или URL. Сохранённая запись не изменяется.
2. В административном журнале используется подпись «Документ автомобиля». Содержимое документов и суммы в журнал не добавляются.
3. Когда новая сумма отличается от связанной траты, пользователь обязан выбрать «Обновить сумму связанной траты» или «Оставить сумму траты прежней». Без выбора запись отклоняется, поля сохраняются. Обновление траты и документа атомарно, повторная трата не создаётся. При сохранении прежней суммы показано явное подтверждение.

Дополнительно: удаление личной траты очищает ссылку документа даже при отключённом контроле внешних ключей SQLite. Ссылка на существующую трату остаётся доступной, если пользователь явно очистил сумму документа, оставив трату прежней.

## Ограничения

Ежемесячную связанную личную трату следует изменять в разделе расходов: из документа можно явно оставить её сумму прежней. Это сохраняет существующие правила генерации ежемесячных расходов.

Полная матрица Firefox из предыдущего протокола остаётся неподтверждённой. Этот этап исправляет выявленные ошибки и не объявляет незавершённые браузерные проверки успешными.
