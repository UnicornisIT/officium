# Ручная проверка документов

Дата: 31.10.2026. Отдельный локальный сервер, отдельная временная база, вымышленные документы. Проверка выполнена через интерфейс встроенного браузера; серверные тесты не выдаются за ручные.

## Подтверждённые сценарии

| Сценарий | Результат |
|---|---|
| Создание служебного автомобиля | Сохранён, признак служебного отображается |
| Вкладка документов и пустое состояние | Доступны |
| Дата окончания раньше выдачи | Сообщение об ошибке, документ не создан |
| ОСАГО с датами и суммой 15 000,50 | Сохранён |
| Сумма при вводе 15000.50 | Преобразуется в 15 000,50 |
| Сумма при вводе 15000,50 | Сохраняется с копейками |
| Повторное редактирование суммы | Отображается 15 000,50 |
| Ввод 1234567,89 | Отображается 1 234 567,89 |
| Личная трата по флагу | В карточке появилась ссылка на личную трату |
| КАСКО с плательщиком «Организация» | Создана отдельная трата организации |
| Карточка траты организации | Транспорт, Страхование, 25 000 ₽, плательщик Организация |
| ПТС без дат и суммы, без флага | Бессрочный, в порядке, без ссылки на трату |
| Правка срока на 10 дней вперёд | Скоро истекает, автомобиль требует внимания |
| Фильтр «Требует внимания» | Автомобиль найден |
| Обзор автомобиля | Ближайший срок документа и статус отображаются |
| Правка срока на вчера | Просрочено, автомобиль требует обслуживания |
| Правка срока на январь 2027 | Автомобиль вернулся в состояние «В порядке» |
| Повторное ОСАГО | Отклонено с понятным сообщением |
| Отрицательная сумма | Отправка блокируется валидацией поля |
| Нулевая сумма | Отклонена сервером |
| Архивирование | Документы доступны только для просмотра, формы отсутствуют |
| Восстановление автомобиля | Доступ к обычной карточке возвращён |
| Прицеп | Вкладка доступна, бессрочный СТС сохранён без траты |
| Чужая карточка под другой учётной записью | Страница 404 |
| Административный журнал | Действие и ID; название полиса и сумма отсутствуют |
| Узкий экран и светлая тема | Поле суммы читается, разделители сохраняются |

## Исправлено во время проверки

Поле суммы документа переведено на текстовый денежный ввод с группировкой разрядов, десятичной запятой и клавиатурой для чисел. Значения с пробелами корректно разбираются сервером. Изменение проверено созданием, сохранением и повторным редактированием через UI.

## Найденные недочёты

1. После ошибки серверной валидации форма закрывается и введённые поля очищаются. Воспроизводится при неправильной хронологии и нулевой сумме. Документ при этом не сохраняется.
2. В административном журнале тип объекта показан как «Неизвестное тип объекта: vehicle_document». Действие переведено, содержимое документов не раскрывается.

## Ограничения ручной проверки

- Во встроенном браузере фактическая ширина узкого окна — 500 px, несмотря на запрос 390 px. Этот прогон не подтверждает ручную проверку ровно на 390 px. Автоматические снимки 390/1440 px находятся в основном отчёте.
- Полная матрица ручных проверок Firefox/WebKit не выполнена: встроенный браузер не позволяет переключить движок. Ранее WebKit прошёл четыре автоматических сценария; полный успешный прогон Firefox не подтверждён.
- Отключение флага, подмена POST с чужим ID, ограничения схемы, откат транзакции, миграции и точные границы 0/14/15 дней подтверждены серверными тестами, но не являются ручными UI-проверками этого прогона.
