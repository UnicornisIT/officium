# Ручная проверка CSV в Excel — 28.10.2026

Проверено в установленном Microsoft Excel 2016 с русскими региональными настройками. Все записи вымышленные: автомобиль «Демонстрация расходов — 10 вымышленных записей».

1. Исходный CSV: UTF-8 BOM, разделитель `;`, 9 колонок, 10 расходов и строка «Итого». Суммы с десятичной точкой импортировались как текст: при выделении G2:G11 Excel показывал только «Количество: 10».
2. Исправление: денежные значения и итог экспортируются с десятичной запятой, без разделителя тысяч. Расчёт в приложении остаётся на Decimal.
3. Новая выгрузка получена с работающего dev-сервера: `/vehicles/reports?vehicle_id=3&date_from=2026-10-01&date_to=2026-10-31&format=csv`.
4. В мастере импорта выбраны UTF-8 и разделитель «точка с запятой», общий формат столбцов. Десятичные разделители вручную не менялись. Для G2:G11 Excel показывает «Среднее: 1999,575», «Количество: 10», «Сумма: 19995,75». G12 содержит числовой итог 19995,75.
5. Сумма всех десяти записей также независимо проверена через Decimal: 19 995,75 ₽. Кириллица, комментарии с точкой с запятой и итог сохранены.

Ограничение CSV: ширина столбцов и оформление не сохраняются. Excel открывает узкие столбцы; даты видны как `#####`, пока столбец не расширен. При открытии через диалог Excel здесь запускался мастер импорта с фиксированной шириной по умолчанию; проверено разделение на колонки с явным выбором `;`.
