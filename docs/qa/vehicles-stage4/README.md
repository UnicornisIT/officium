# Этап 4 — топливо и заправки

Дата проверки: 29 октября 2026 года. Все автомобили, АЗС и суммы в примерах вымышлены.

## Реализация

- Отдельная сущность заправки, одна запись на автомобиль в день; литры сохраняются с точностью 0,001.
- Атомарная запись заправки, пробега и личной траты либо траты организации.
- При редактировании связанная трата обновляется. При смене плательщика прежняя финансовая запись заменяется в той же транзакции, без двойного учёта. Для организационной траты с оплатой водителем или возмещением сначала необходимо снять соответствующие отметки.
- Замер с совпадающим пробегом на ту же дату используется повторно. Чужой ручной замер или замер обслуживания не переносится при редактировании заправки; собственный замер топлива можно перенести или исправить.
- Расход строки считается только между соседними полными заправками с растущим пробегом. Средний расход периода учитывает все доливы после первой и до последней полной заправки; литры первой полной заправки исключаются.
- Средняя цена взвешивается по объёму. Обзор показывает последние пять заправок и сумму текущего месяца; вкладка позволяет выбрать период.
- Архив доступен только для просмотра; прицепы не имеют вкладки и маршрутов заправки. Электромобили принимаются без специальных ограничений.
- Действия в журнале содержат только тип сущности и ID; персональные названия, суммы, АЗС и комментарии в событие заправки не передаются.
