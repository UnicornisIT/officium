# Фиксы аудита автомобилей 0–3

Включены в этап 6 по разрешению владельца проекта.

- due_vehicles загружает readings пакетно через selectinload; количество
  SELECT не растёт на каждый автомобиль (с поправкой на чанки SQLAlchemy).
- technical_condition уже принимает day и предвычисленный mileage;
  сбор напоминаний загружает зависимости пакетно и передаёт оба значения.
- Snooze принимает days=3 (1–365) и настраивается в форме напоминания.
- Смена kind запрещена при наличии VehicleCost, как и при прочей истории.
  Виды трат проверяются существующим vehicle_cost_service.KINDS.

Проверки: test_vehicle_notifications и существующие тесты сервиса автомобилей.
