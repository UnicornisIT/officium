# Актуальные снимки интерфейса

Все изображения встроенного `/documentation` переснимаются из работающего
приложения, а не рисуются и не редактируются вручную.
Каталог: `static/images/documentation/`, перечень —
[manifest.json](../static/images/documentation/manifest.json).
Пять прежних иллюстраций (`dashboard`, `expenses`, `analytics`,
`financial-plan`, `documentation-preview`) заменены свежими; добавлены снимки
целей, ввода доходов/долга, импорта, автомобилей, профиля и приватности.

Актуальный комплект учитывает компактный глаз возле заголовков/действий
и ряд «глаз → Отчёты → Аналитика» под добавлением автомобиля. Профиль показывает
одну карточку «Уведомления»: ежемесячные расходы первыми, автомобильные
напоминания вторыми, между ними горизонтальная линия.
Локальная страница сравнения до и после хранится отдельно и не входит
в поставку релиза; встроенное руководство показывает новый интерфейс.

## Воспроизведение

Из корня проекта установите Python-зависимости, npm-зависимости и Chromium
Playwright. Обычный запуск тестов не перезаписывает изображения: требуется
явный флаг обновления.

```bash
python -m pip install -r requirements.txt
npm install
npx playwright install chromium
UPDATE_DOCUMENTATION_SCREENSHOTS=1 npx playwright test tests/e2e/documentation-capture.spec.js --project=chromium
```

```powershell
$env:UPDATE_DOCUMENTATION_SCREENSHOTS = '1'
npx playwright test tests/e2e/documentation-capture.spec.js --project=chromium
Remove-Item Env:UPDATE_DOCUMENTATION_SCREENSHOTS
```

Штатный `playwright.config.js` поднимает `scripts/e2e_server.py` с отдельной
временной SQLite-базой `officium-playwright.sqlite`. Seed-скрипт отказывается
работать с другим именем базы и требует dev-пользователя, созданного тестом.
Для альтернативного изолированного runner путь передаётся через
`OFFICIUM_E2E_DATABASE`; это должен быть тот же файл, который использует сервер.
Не направляйте пересъёмку на production: сценарий создаёт вымышленные записи.

## Состав и ограничения

Основные снимки — Chromium, браузер 1440×1000, светлая тема. Профиль также
показан в мобильном Mini App шириной 390 px в тёмной теме: `telegram-mini-app.png`
показывает первый экран 390×844, `profile-mobile.png` — всю карточку уведомлений.
Для захвата карточки высота viewport увеличивается до 2400 px, чтобы нижняя
навигация не закрывала её содержимое. В манифесте такой захват имеет `selector`.
Состояние страницы,
viewport, тема, тип захвата и UTC-время сохраняются в манифесте.
При точечном обновлении снимка его время записывается в `images[].capturedAt`,
а время последнего изменения комплекта — в `updatedAt`.
Размеры PNG также записываются в манифест и выводятся как HTML width/height:
иллюстрации не растягиваются и резервируют место до загрузки.
Даты демонстрационных записей привязаны к месяцу съёмки.

SDK Telegram подменяется локальным ответом. Мобильные снимки показывают
интерфейс Mini App, не реальный чат и не доказательство доставки уведомлений.
Кнопка тестовой отправки не нажимается; личные данные и реальные аккаунты
не используются. Анимации на время снимка отключаются системной настройкой
уменьшения движения, чтобы фиксировать установившееся состояние.

Картинки в HTML-руководстве открываются в полном размере. Параметр версии
в URL заставляет браузер загрузить новый комплект вместо старого кэша.
При следующем обновлении набора увеличьте эту версию в
`templates/_documentation_screenshot.html`.

## Проверка

1. Убедитесь, что все пути из манифеста существуют и соответствуют реальным страницам.
2. Просмотрите дашборд, профиль, автомобильное меню и мобильный Mini App.
3. Проверьте `/documentation` в обеих темах на 390 и 1440 px: все 12 разделов,
   поиск, оглавление, изображения без 404 и горизонтального переполнения.
4. Запустите `python -m unittest discover -s tests -p test_documentation.py` и
   `npx playwright test tests/e2e/documentation-guide.spec.js --project=chromium`.

Исторические `docs/qa/**` сохраняют исходные доказательства проверок и
сравнения «до/после». Их изображения не подключены к действующему руководству;
текущий комплект имеет собственный манифест и заменяет их как справку по UI.
