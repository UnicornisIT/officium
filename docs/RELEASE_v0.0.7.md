# officium v0.0.7

Релиз полностью обновляет административную панель, не меняя финансовые расчёты,
модель данных и схему базы данных.

## Что изменилось

- единый Premium Fintech-интерфейс для всех административных страниц;
- адаптивная боковая навигация и компактная верхняя панель;
- светлая и тёмная темы, клавиатурный фокус, увеличенные мобильные цели нажатия и
  поддержка `prefers-reduced-motion`;
- обзор с ключевыми показателями, состоянием системы и последними событиями;
- поиск, фильтры, сортировка и серверная пагинация пользователей;
- фильтры журнала по пользователю, событию и периоду;
- отдельный read-only раздел долгов и платежей;
- безопасная системная диагностика без строк подключения и секретов;
- человекочитаемые названия ролей, статусов, событий и полей БД; технические имена
  остаются доступными в подсказках;
- единый набор подтверждений для блокировки, смены роли, удаления и обновления;
- новая фирменная символика, favicon и app-icon;
- тестовая имперсонализация недоступна в production.

## Совместимость и риски

- миграций БД в этом релизе нет;
- финансовая логика, авторизация, CSRF-защита и существующие ограничения ролей не
  изменены;
- новые маршруты `/admin/finance` и `/admin/system` только читают данные;
- `/admin/system`, экспорт, настройки, справочники и обновление сервера доступны
  только супер-администратору.

## Обновление production

Целевая конфигурация: Ubuntu, `/opt/officium`, пользователь `officium`, виртуальное
окружение `/opt/officium/venv`, MySQL и служба `officium.service`.

Предпочтительный путь — открыть «Административная панель → Обновление сервера» и
установить опубликованный релиз `v0.0.7`. Настроенный updater сам проверит тег,
создаст резервную копию, установит зависимости, применит миграции (для этого
релиза изменений нет), перезапустит службу и выполнит health-check.

После обновления проверьте:

```bash
sudo systemctl is-active officium.service
sudo journalctl -u officium.service -n 100 --no-pager
cd /opt/officium
sudo -u officium /opt/officium/venv/bin/python -m unittest discover -s tests -q
```

Затем откройте `/admin`, проверьте обзор, список пользователей, журнал, обе темы и
мобильное меню. В production кнопки тестового пользователя быть не должно.

## Откат

Поскольку схема БД не меняется, при проблеме интерфейса достаточно остановить
службу, сохранить журналы, вернуть checkout к предыдущему проверенному тегу,
восстановить зависимости этого тега и запустить службу:

```bash
sudo systemctl stop officium.service
cd /opt/officium
sudo -u officium git fetch origin --tags
sudo -u officium git checkout --detach v0.0.6
sudo -u officium /opt/officium/venv/bin/pip install -r requirements.txt
sudo systemctl start officium.service
sudo systemctl is-active officium.service
```

Если до обновления менялись пользовательские данные или возникло повреждение БД,
не выполняйте `flask db downgrade`: сохраните проблемную БД и восстановите
предрелизный MySQL-дамп по процедуре из `docs/DEPLOYMENT.md`, раздел «Откат».
