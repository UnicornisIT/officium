# Проверка остатка после платежа через Telegram

1. Создать в веб-приложении кредит без процентов на 25 000 ₽.
2. В связанном Telegram-боте выбрать «Платёж», выбрать этот долг и ввести 2 500 ₽.
3. Подтвердить платёж с сегодняшней датой: ответ должен содержать задолженность 22 500 ₽.
4. Повторить на отдельном долге с датой платежа 28 ноября 2026 года: ответ также должен содержать 22 500 ₽.
5. Проверить остаток 22 500 ₽ в веб-приложении и убедиться, что бот завершил сценарий ввода платежа.
6. Для долга с непогашенными процентами проверить обе строки: остаток основного долга и задолженность с процентами. Расчёт учитывает записанный платёж, включая платёж с будущей датой.

Автоматическая проверка: `python -m pytest tests/test_telegram_payment_recalculation.py -q`.
Живая проверка в Telegram требует связанного аккаунта; приведённые шаги предназначены для её выполнения вручную.
