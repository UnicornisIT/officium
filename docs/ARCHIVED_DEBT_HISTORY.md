# Архив долгов и история платежей

Архивирование исключает долг из активных карточек, остатка задолженности,
ближайших платежей и будущих обязательств финансового плана. Оно не отменяет
записанные платежи. `payments_this_month` и `total_payments` включают все
платежи пользователя за выбранный календарный месяц независимо от текущего
статуса долга. Это правило действует для закрытого и текущего месяца.
Восстановление карточки не создаёт новых платежей.

Раньше сводка фильтровала платежи по текущему статусу `active`, поэтому архив
менял прошлые отчёты. Теперь главный экран, финансовый отчёт и сводка бота
получают полную историю из общего сервиса. Финансовый план по-прежнему
планирует обязательства только активных долгов, а не исторический cash flow.

## Платёж, также записанный расходом

`total_expenses` и `total_payments` сохраняют полные суммы исходных записей.
Для расчёта денежного оттока одна операция учитывается один раз, если расход
категории `loans` явно связан через `repayment_debt_id` с тем же долгом и
точно совпадает с платежом по дате и сумме до копеек. Каждая запись платежа
может сопоставиться только с одним расходом. Статус долга на сопоставление
не влияет. Только название или совпадение суммы без связи недостаточны.
Разные даты, несовпадающие суммы и объединённые платежи автоматически не
сопоставляются: однозначной связи с конкретной операцией для них нет.

- `cashflow.payments_in_expenses` — сумма сопоставленных операций.
- `cashflow.payments_outside_expenses` — платежи сверх учтённых расходов;
  эта сумма показана в формуле финансового отчёта.
- `total_outflow = total_expenses + total_payments - payments_in_expenses`.
- `free_balance = total_incomes - total_outflow - goal_transfers.net`.
- Обязательные списания складываются из регулярных расходов и платежей,
  с исключением их пересечения; прогноз остатка также исключает пересечение.
  Сопоставленный разовый расход относится к платежам по долгам и повторно
  не включается в разовые и гибкие списания.

Миграция и исправление записей не нужны: меняется только расчёт отчёта.
Полное удаление долга, в отличие от архива, по-прежнему удаляет его платежи.
Проверки: `tests/test_finance_summary.py` — архив/восстановление, будущий
план, границы месяца, изоляция пользователей, копейки, повторный расчёт
и сопоставление расходов без повторного использования платежа.
